ThreatLocker blocks applications it does not recognize, including the Telivy installer. ThreatLocker ships a built-in **Telivy Agent** application, so allowing Telivy takes one policy. Set it up before you deploy the agent.

## Create the Telivy policy

1. In ThreatLocker, open the **Application Control** tab on the left. Choose what the policy applies to, either a computer group or a single machine, and select **New Policy**.

   <img src="/images/threatlocker-and-telivy-policy-during-installation/threatlocker-and-telivy-policy-during-installation-1.png" alt="ThreatLocker Application Control tab with the New Policy button" />

2. Give the policy any name. In the selected applications box, type `Telivy` and pick **Telivy Agent (built-in)**, then select **Create**.

   <img src="/images/threatlocker-and-telivy-policy-during-installation/threatlocker-and-telivy-policy-during-installation-2.png" alt="ThreatLocker new policy form with the built-in Telivy Agent application selected" />

3. Select **Deploy policies** in the top right corner.

   <img src="/images/threatlocker-and-telivy-policy-during-installation/threatlocker-and-telivy-policy-during-installation-3.png" alt="ThreatLocker Deploy policies button in the top right corner" />

## Auto-update and ThreatLocker

ThreatLocker also blocks MSI-based updates. When you create an assessment with ThreatLocker as its antivirus, Telivy turns [auto-update](/products/risk-assessments/auto-update) off for that assessment. You can turn it back on in the assessment's update settings.

If the installer is blocked anyway, the agentless scanner may still complete, and the device shows an **Agentless Scan** badge. See [Devices scanned without the agent](/products/risk-assessments/install-telivy-agent-windows#devices-scanned-without-the-agent).

For other questions, contact support@telivy.com or ThreatLocker support.
