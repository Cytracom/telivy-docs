<AccordionGroup>
    <Accordion title="How do I check if Telivy is down?">
        Live platform status is at [status.telivy.com](https://status.telivy.com/).
    </Accordion>

    <Accordion title="I bookmarked the Telivy login page and the bookmark doesn't work. What should I do?">
        The login page uses a redirect link that expires after a while for security
        reasons. Bookmark [portal.telivy.com](https://portal.telivy.com) instead.
    </Accordion>

    <Accordion title="Where do I manage my Telivy account settings?">
        See [Telivy Account Settings Overview](/getting-started/set-up-telivy-account/overview).
    </Accordion>

    <Accordion title="Can several users see the same assessment?">
        Yes. Each assessment has one **owner** (the user who created it, or whoever it was
        reassigned to) and can have extra **shared users**. Shared users see the assessment
        in their dashboard with full edit access. They can rescan, view reports, archive,
        convert, and receive the same alert emails.

        Share an assessment from its page with **More > Manage Access**. The owner, any
        Account Admin in the same account, or a Telivy Admin can do this. Sharing doesn't
        change anyone's account role in Unity, and a Telivy User shared on one assessment
        gets no access to any other.

        For how sharing differs from reassigning, see
        [sharing and reassigning assessments](/getting-started/set-up-telivy-account/overview).
    </Accordion>

    <Accordion title="Can I move assessments to a user in one of my sub-agencies?">
        Yes, if you are an admin in a master agency. Select the assessments on the
        Assessments list, click **Reassign**, choose the sub-agency under **Agency**, and
        then pick the user. Telivy files the assessments under a matching company in that
        sub-agency and creates the company if it doesn't exist there yet. See
        [reassigning assessments to a sub-agency](/getting-started/set-up-telivy-account/overview).
    </Accordion>
</AccordionGroup>
