<AccordionGroup>
  <Accordion title="How do I start installing the agent for a Risk Assessment?">
    Create the assessment, then open **Setup > Deploy Agents** for the install command and downloads. [Start a new Risk Assessment](/products/risk-assessments/start-a-new-risk-assessment) covers creating it, and [Install the Telivy agent on Windows](/products/risk-assessments/install-telivy-agent-windows) covers deployment by RMM, by installer, or without an agent.
  </Accordion>

  <Accordion title="What software does Telivy install?">
    A Windows service, the Telivy Agent, plus the scanner, launcher, and updater executables in `C:\Program Files (x86)\Telivy\Telivy Agent`. [Whitelist Telivy with AV/EDR](/products/risk-assessments/whitelist-telivy-with-av-edr#what-each-executable-does) lists each file and what it does. Agentless scans install nothing.
  </Accordion>

  <Accordion title="Which devices should I install Telivy on?">
    Supported servers, laptops, and desktops. For the best coverage, install it on as close to every device as you can. If that is not possible, pick a mix, for example one device from each department such as HR, accounting, and sales, so the results reflect the whole organization.
  </Accordion>

  <Accordion title="How do I check that Telivy ran on a device?">
    The device appears in the assessment's device list, under **Setup > Deploy Agents > Deployment Status** and on **Inventory > Endpoints**, with its installation details.

    If it does not appear, usually either:

    1. An antivirus, EDR, firewall, or similar tool blocked it. See [Whitelist Telivy with AV/EDR](/products/risk-assessments/whitelist-telivy-with-av-edr).
    2. The device was added to a different assessment. Uninstall it from that one and install it again with the right assessment's command.

    On the device itself, you can check that "Telivy" is listed under installed programs in Control Panel.
  </Accordion>

  <Accordion title="A device shows Agentless Scan. Why?">
    The device was scanned by the agentless scanner instead of having the agent installed. This often happens when an EDR such as ThreatLocker blocks the agent installer, because the scanner still finishes. Allow Telivy in the EDR and run the **Agent Installer** on the device. See [Devices scanned without the agent](/products/risk-assessments/install-telivy-agent-windows#devices-scanned-without-the-agent).
  </Accordion>

  <Accordion title="Why is a scan or rescan taking so long?">
    A scan can only finish while the device stays on long enough, usually about two hours without interruption. If a scan is still running after the device has been online for a long time, email support@telivy.com and we will look into it.
  </Accordion>

  <Accordion title="How do I remove older third-party agents such as Nodeware, Augmentt, or Actifile?">
    Telivy's current agent does everything in-house. To remove the older agents, run the matching command in PowerShell as Administrator.

    **Nodeware**

    ```powershell
    Invoke-Command -ScriptBlock ([scriptblock]::Create([System.Text.Encoding]::UTF8.GetString((New-Object Net.WebClient).DownloadData('https://install.telivy.com/uninstall-nodeware.ps1'))))
    ```

    **Augmentt**

    ```powershell
    Invoke-Command -ScriptBlock ([scriptblock]::Create([System.Text.Encoding]::UTF8.GetString((New-Object Net.WebClient).DownloadData('https://install.telivy.com/uninstall-augmentt.ps1'))))
    ```

    **Actifile**

    ```powershell
    Invoke-Command -ScriptBlock ([scriptblock]::Create([System.Text.Encoding]::UTF8.GetString((New-Object Net.WebClient).DownloadData('https://install.telivy.com/uninstall-actifile.ps1')))) -ArgumentList @('ACTIFILE_UNINSTALL_KEY')
    ```

    For the Actifile uninstall key of a past assessment, email support@telivy.com with the assessment names.
  </Accordion>
