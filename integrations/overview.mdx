Account admins connect most integrations from **Account → Integrations** in the Telivy
portal. Webhooks have their own section at **Account → Webhooks**. The Security API, Rewst,
and the MCP server share one agency API key, so regenerating it disconnects all three.

## PSA

Send security findings to your PSA as tickets, and resolve them in Telivy when the ticket
closes.
