Account admins connect most integrations from **Account > Integrations** in the Telivy
portal. Webhooks have their own **Webhooks** section in the same menu, and the Security API
and MCP server use an agency API key.

## PSA

Send security findings to your PSA as tickets, and resolve them in Telivy when the ticket
closes.

<CardGroup cols={2}>
  <Card title="ConnectWise PSA" icon="ticket" href="/integrations/connectwise">
    Service tickets that follow merges and resolve the finding when closed
  </Card>
  <Card title="Autotask PSA" icon="ticket" href="/integrations/autotask">
    Tickets with severity-based priority that resolve when completed
  </Card>
  <Card title="HaloPSA" icon="ticket" href="/integrations/halopsa">
    Halo tickets through an API application
  </Card>
  <Card title="Grouped tickets" icon="layer-group" href="/integrations/psa-grouped-tickets">
    One ticket per finding, or one per scan for each finding category
  </Card>
</CardGroup>
