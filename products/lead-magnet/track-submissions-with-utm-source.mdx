When the Lead Magnet runs in several places, such as your website, an email campaign and a social ad, a UTM source tells you which one each submission came from. How you add it depends on how the Lead Magnet is set up.

## With the Easy-Go link

Add `utmSource` as a query parameter. For a campaign called `facebook-campaign-2`:

```
https://portal.telivy.com/start/{your-agent-id}?utmSource=facebook-campaign-2
```

Submissions made through a link without `utmSource` are recorded with the source `Unknown`.

## With a custom form

Add `utmSource` to the form data before sending it:

```javascript
formData.append("agentId", "your-agent-id");
formData.append("utmSource", "facebook-campaign-2");
```

See [Configure with Custom Form](/products/lead-magnet/configure-with-custom-form) for the full form example.

## See the source on your dashboard

Each submission shows the value you set in the **UTM Source** column.
