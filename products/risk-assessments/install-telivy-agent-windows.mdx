Telivy collects data from Windows devices in one of two ways. The **agent** installs as a Windows service, stays on the device, and keeps scanning on a schedule. The **agentless scanner** runs once, leaves nothing installed, and gives you a one-time snapshot. The instructions for both are on the assessment's **Setup** tab under **Deploy Agents**.

Before you deploy, allow Telivy in the client's antivirus or EDR. See [Whitelist Telivy with AV/EDR](/products/risk-assessments/whitelist-telivy-with-av-edr), and if the client uses ThreatLocker, the [ThreatLocker policy guide](/frequently-asked-questions/threatlocker-and-telivy-policy-during-installation).

## Install the agent

### With an RMM (recommended)

Each assessment has its own install command, which you can run from any RMM.

1. Open the assessment and go to **Setup > Deploy Agents**.
2. Under **Agent Installer**, find **Instructions for RMM** and select **Copy** next to the install command.
3. In your RMM, run the command from a PowerShell terminal or the Execute Script option, as Administrator or the System user.

![Agent Installer card with Download Telivy Installer (.exe), Copy Link to Download and the RMM command with its Copy button](/images/install-telivy-agent-windows.png)

### With the installer

If you have no RMM access, select **Download Telivy Installer (.exe)** and run it as Administrator on each device. The agent needs admin rights to install.

## Agentless deployment

Use the agentless scanner when you cannot install software on a device, or when you want employees to run the scan themselves. Select **Download Telivy Scanner (.exe)**, or **Copy Link to Download** and send employees these steps:

1. Download the software from the link.
2. Double-click to run it.
3. When asked for admin access, select **Yes**. If that gives an error, select **No**.

The scanner runs as Administrator when the user has admin rights and as a standard user otherwise. A standard-user scan only sees what that user can open, so PII and password coverage is narrower. Agentless scans leave nothing on the device, so there is nothing to uninstall.

### Devices scanned without the agent

On the assessment's **Inventory > Endpoints** page, a device that was scanned without the agent shows an **Agentless Scan** badge, and its **Agent Status** reads "Not installed, scanned agentlessly". These results are a one-time snapshot. The device cannot be rescanned or uninstalled from the portal and gets no continuous monitoring or alerts.

![Deployment Status list with Agentless Scan badges next to devices scanned without the agent](/images/assessment-deployment-status-2.png)

When some or all devices in an assessment were scanned this way, a notice above the device list says how many. If no device runs the agent, **Rescan All** and **Uninstall All** are disabled because there is nothing to send the command to. To fix this, run the **Agent Installer** on those devices.

The scanner still completes when an EDR such as ThreatLocker blocks the agent installer. That is the usual reason a device you meant to install the agent on shows up as agentless.

## What happens after install

1. With an RMM install, the device first downloads the MSI package from `install.telivy.com`. If the download fails, check the antivirus or EDR.
2. The installer extracts the agent files, sets registry entries, and creates and starts the Telivy Agent Windows service.
3. Once an hour, the agent sends a heartbeat and starts the Telivy Scanner. The scanner only collects what is due, so an hourly start is not an hourly full scan. [Scanning Schedule](/products/risk-monitoring/scanning-schedule) lists how often each check runs.
4. On its first run, the scanner registers the device in your assessment with its hostname, OS, and other identifying details.
5. The scanner then runs the vulnerability, application, PII, and password scans, and the device shows as **In Progress** in the portal.
6. The agent checks every hour whether the first scan has finished. The PII scan usually takes longest, depending on how many files are on the device.
