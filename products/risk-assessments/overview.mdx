A Risk Assessment measures a client's security from the inside as well as the outside. It includes everything in an [External Assessment](/products/external-assessments/overview) and adds data from the Telivy agent on the client's devices and from their cloud accounts.

It covers:

- **Network scanning:** the external attack surface plus internal devices, checked for vulnerabilities. Each vulnerability gets a [Risk Priority Score](/scoring/risk-scoring#risk-priority-score) so you know what to fix first.
- **Application scanning:** the applications installed on each device, listed under **Inventory > Installed Apps**.
- **Web activity:** the websites people visit from company devices, which ones are AI tools, and which ones need review. See [Web activity and AI use](#web-activity-and-ai-use) below.
- **[Data Security](/products/risk-assessments/data-security):** PII stored on devices, such as SSNs, card numbers, and health IDs, with a dollar value for the exposure.
- **[Identity and Access Management](/products/risk-assessments/identity-and-access-management):** passwords saved in browsers, checked for breaches, weakness, and reuse.
- **Dark Web:** leaked credentials and personal details tied to the client's domains, including usernames, passwords, IP addresses, emails, physical addresses, and phone numbers.
- **Cloud security:** [Microsoft 365](/products/risk-assessments/microsoft-365-security) and [Google Workspace](/products/risk-assessments/google-workspace-security) accounts, MFA, sign-ins, Secure Score gaps, and tenant policies.
- **[Compliance](/products/risk-assessments/compliance):** findings mapped to the CIS Critical Security Controls.

## Web activity and AI use

The agent records which websites are visited from each device. Find them on the assessment's **Inventory** tab under **Web Activity**, which has two views:

- **Websites** lists each site once, with its **Category**, whether it is an **AI** tool, **Total Visits**, a **Risk** rating, and the number of **Users**. The summary above it shows **Total Websites Found** and **High Risk Websites**. Expand a row to see why the site got its rating, its characteristics (for example "Generative AI", "Handles health data", or "File sharing"), and which users and devices visited it.
- **Activity** lists every visit by website, user, and device with the last visit date. Filter it by device, user, category, or website. Selecting a site in the **Websites** view opens its activity.

The **AI** column reads **Yes** when Telivy has classified the site as a generative AI tool, **No** when it has classified it and it is not one, and **Unknown** when the site has not been classified yet. Treat **Unknown** as unreviewed, not as safe.

Two different things raise a site's **Risk** rating: it can carry company or personal data off the network, or it should not be used on a work machine at all. An AI assistant and a gambling site can both be High for completely different reasons, so expand the row to see which applies.

Use the **Needs review** filters to narrow the list:

| Filter | Shows |
| --- | --- |
| AI | Sites classified as AI tools, where prompts can carry company data off the network |
| Sensitive data | Sites that handle health, financial, payment, or credential data |
| Not work-related | Social, streaming, gaming, shopping, adult, and gambling sites |
| Shadow IT | File sharing, remote access, and unsanctioned tools that bypass IT |

On the **Overview** tab, the **AI Exposure Score** card summarizes AI use with **Total AI Websites**, **Unique AI Users**, and the top AI sites. **View all websites** opens the **Web Activity** tab. [AI scoring](/scoring/ai-scoring) explains how the score is calculated.
