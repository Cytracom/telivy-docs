---

Antivirus and EDR products can block the Telivy installer or stop the agent from talking to Telivy. Allow the entries below before you deploy, and work down the list only as far as you need to.

## If the installation fails

1. Allow the domain `install.telivy.com`.
2. If it still fails, allow the folder `C:\Program Files (x86)\Telivy`.

## If Telivy installs but cannot connect

Allow these domains:

- `agent-v1.telivy.com`
- `install.telivy.com`

And these executables:

- `C:\Program Files (x86)\Telivy\Telivy Agent\Telivy.Agent.Windows.exe`
- `C:\Program Files (x86)\Telivy\Telivy Agent\Telivy.Scanner.Windows.exe`
- `C:\Program Files (x86)\Telivy\Telivy Agent\Telivy.Launcher.Windows.exe`
- `C:\Program Files (x86)\Telivy\Telivy Agent\Telivy.Updater.Windows.exe`

## If neither works

Allow broader rules:

- Domains: `*.telivy.com`
- Folder: `C:\Program Files (x86)\Telivy\Telivy Agent`

If the client uses ThreatLocker, use the built-in Telivy policy instead. See [ThreatLocker and Telivy](/frequently-asked-questions/threatlocker-and-telivy-policy-during-installation).

## What each executable does

| Executable | Purpose |
| --- | --- |
| `Telivy.Agent.Windows.exe` | Runs as a Windows service under the SYSTEM account. It starts the scanner on a schedule and sends a heartbeat to Telivy. |
| `Telivy.Scanner.Windows.exe` | Performs the scan. |
| `Telivy.Launcher.Windows.exe` | Runs the scanner in a signed-in user's context, which the SYSTEM service cannot do on its own. |
| `Telivy.Updater.Windows.exe` | Updates the agent when [auto-update](/products/risk-assessments/auto-update) is on. |

For the order of events after install, see [Install the Telivy Agent on Windows](/products/risk-assessments/install-telivy-agent-windows#what-happens-after-install).
