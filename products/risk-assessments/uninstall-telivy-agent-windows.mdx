Uninstalling removes the Telivy agent from the device. The data from its latest scan stays in the portal, so it remains part of the assessment and of any report you generate.

## Uninstall from the portal

In the assessment's device list, select **Uninstall** on a single device, or **Uninstall All** to remove the agent from every device in the assessment.

Devices scanned with the agentless scanner have nothing installed and show an **Agentless Scan** badge. They have nothing to uninstall. If no device in the assessment runs the agent, **Uninstall All** is disabled.

### Uninstall is scheduled, not instant

Selecting **Uninstall** flags the device, and the agent acts on the flag the next time it checks in. The device does not need to be online when you select it. Until then, the device shows **Uninstall Scheduled**. A device that is online usually picks it up within an hour, because the agent checks in about once an hour.

<Warning>
  If a device stays at **Uninstall Scheduled** for hours or a whole day, the flag is not reaching it. Either the Telivy Agent service is not running or the device cannot reach Telivy. Uninstall it manually with one of the commands below.
</Warning>

## Uninstall manually

Run an uninstall command on the device itself, in a terminal or through your RMM. Use this for devices that never pick up the scheduled uninstall, or when you do not want to wait. The two options handle the data already on the device differently.

### Option 1: Standard Uninstall (recommended)

Use this for routine removal. It keeps the device's local PII database, so if Telivy is reinstalled later, the next scan is faster. It works on agent version 30.0.0.0 and later.

Run as Administrator:

```powershell
& "C:\Program Files (x86)\Telivy\Telivy Agent\Telivy.Scanner.Windows.exe" --IsUninstallMode=true
```

### Option 2: Full Wipe

Use this to remove all Telivy data from the device, or to uninstall agents older than 20.0.0.0.

<Warning>
  Full Wipe removes all Telivy history **and the PII database** from the device. Use it only to remove Telivy completely or to fix a corrupted installation. If you might reinstall and want to keep the existing PII data, use Standard Uninstall.
</Warning>

Run in PowerShell as Administrator, replacing `<DEEPSCAN_ID>` with the assessment's Deep Scan ID from its **Setup** tab:

```powershell
Invoke-Command -ScriptBlock ([scriptblock]::Create([System.Text.Encoding]::UTF8.GetString((New-Object Net.WebClient).DownloadData('https://install.telivy.com/uninstall-all.ps1')))) -ArgumentList @('<DEEPSCAN_ID>', '')
```

The **Setup > Deploy Agents** instructions include both commands with **Copy Standard Command** and **Copy Full Wipe Command** buttons.
