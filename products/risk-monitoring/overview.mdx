## Overview

A one-time assessment shows where a client stands on the day it ran. Risk Monitoring, labelled **Continuous Monitoring** in the portal, keeps that picture current by rescanning the client on a schedule you choose and recording a snapshot after each scan, so you can show the client how their posture moves over time.

Pair it with [Alerts](/products/risk-monitoring/alerts), which tell you about specific changes such as a new breach or a new critical vulnerability as soon as Telivy finds them.

## Requirements

| Requirement | Detail |
|---|---|
| Assessment type | Risk Assessment. External scans can be monitored as a prospect with **Monitor Prospect**. |
| Plan | Monitoring must be included in your Telivy plan, either for your agency or for the client's company. If it is not, the button shows **Monitoring is not enabled on your plan**. Contact [accounts@telivy.com](mailto:accounts@telivy.com) to add it. |
| Telivy Agent | Installed and reporting on the client's devices, so endpoint data can be refreshed on each rescan |

## Turn on Continuous Monitoring

You can turn it on when you create the assessment, or later on an existing one.

- **When creating an assessment**, tick **Schedule Recurring Scans** under **Recurring Scans** and pick a **Scan Frequency**.
- **On an existing assessment**, click **Enable Continuous Monitoring** on the assessment and confirm. The first scan runs straight away, and the assessment then rescans monthly by default. Unity partners manage monitoring per client through Unity: for a client linked to a Unity customer, the assessment offers **Enable Recurring Scans** or a link to the client's row on the **Unity** tab instead.

<Warning>
  Turning on Continuous Monitoring for an existing one-time assessment clears its current data and starts recording snapshots from the first monitored scan onward.
</Warning>

## Change the scan frequency

Once monitoring is on, the assessment's **More** menu has **Scan Settings**.

1. Open the assessment in the Telivy portal.
2. Click **More**, then **Scan Settings**.
3. Under **Automated Scan Frequency**, choose a frequency.

| Frequency | Suits |
|---|---|
| Weekly | High-risk clients, clients under active remediation, or clients with a recent incident |
| Monthly | Most managed clients |
| Quarterly | Simple environments, or assessments used mainly for periodic reviews |
| Disable Monitoring | Assessments where you want to run scans manually |

Frequency is set per assessment, so each client can run on its own schedule. You can still trigger a manual rescan at any time.

This setting controls how often the client's computers are fully rescanned. Some checks keep their own schedule whatever you pick: everything Telivy checks from the outside is refreshed weekly, and connected Microsoft 365 and Google Workspace tenants are read daily. [Scanning Schedule](/products/risk-monitoring/scanning-schedule) explains what is checked when, and why findings sometimes change between rescans.

## FAQ

<AccordionGroup>
  <Accordion title="I don't see Scan Settings in the More menu. Why?">
    **Scan Settings** appears only once Continuous Monitoring is on for that assessment. Turn it on with **Enable Continuous Monitoring** first. If that button says monitoring is not enabled on your plan, contact [accounts@telivy.com](mailto:accounts@telivy.com).
  </Accordion>

  <Accordion title="Does a rescan count as a new assessment for billing?">
    No. Scheduled rescans update the existing assessment and do not create new billable assessments.
  </Accordion>

  <Accordion title="What does a rescan cover?">
    The full set of checks in the assessment: devices with the agent installed, the external view of the client, and any connected Microsoft 365 or Google Workspace tenant. A rescan replaces the current findings. Earlier results are kept as snapshots in the assessment's history, which is what the trend charts are drawn from.
  </Accordion>

  <Accordion title="Why did findings change between rescans?">
    Some checks run on their own schedule. The outside view refreshes weekly, connected cloud tenants are read daily, and newly published vulnerabilities are compared weekly against the software Telivy already knows about, so findings can appear without any device being touched. [Scanning Schedule](/products/risk-monitoring/scanning-schedule) breaks it down.
  </Accordion>

  <Accordion title="Can different clients use different frequencies?">
    Yes. Frequency is set per assessment.
  </Accordion>

  <Accordion title="How do I hear about new findings between reviews?">
    Set up [alert policies](/products/risk-monitoring/alerts) for the categories you care about, such as new vulnerabilities, dark web exposure, or Microsoft 365 accounts without MFA.
  </Accordion>
</AccordionGroup>
